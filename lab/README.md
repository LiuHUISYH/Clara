# 虚拟实验室

`lab/src` 是虚拟实验室的 React 源码。运行时不依赖 Node 或开发服务器：`index.html`
直接加载已经打包好的 `lab/chem-lab.js`。

## 当前进度

- ✅ 步骤 1：三块基础骨架（左侧器材/试剂库、中间点阵实验台、底部实验日志）。
- ✅ 步骤 2：从左侧拖拽器材到实验台并在画布内移动；点击选中后出现操作条，
  容器可“加入试剂 / 倒出 / 清空 / 移除”，试剂也可直接拖到容器上。
- ✅ 步骤 3：试剂、体积、温度、pH 与容器内物质列表；酒精灯点燃后按距离加热，
  温度实时显示在容器副标题，液体到沸点会写入警告日志，移开后自然降温。
- ⏳ 步骤 4：基于规则的沉淀、气泡、变色反应。
- ⏳ 步骤 5：温度阈值触发的反应现象（如 NaHCO₃ 受热分解）。

## 已实现的交互细节

| 能力 | 说明 |
| --- | --- |
| 器材 / 试剂库 | 6 个分类、28 项；点击分类折叠，点击条目直接放入实验台 |
| 拖拽 | `@dnd-kit/core`：库里拖入画布、画布内移动、试剂拖到容器上 |
| 选中 | 点击器械出现底部操作条；Esc 或点击空白取消选中 |
| 容器状态 | `contents[]`（试剂、体积、温度）+ `volume` / `ph` / `color` / `temperature`，所有变更统一经过 `syncItem()` |
| 倒液 | 容器间拖拽按目标容量与剩余量部分转移，保留温度与 pH |
| 加热 | 酒精灯“点燃 / 熄灭”；`HEAT_RANGE = 122`、`HEAT_RATE = 4°C/s`、`COOL_RATE = 2°C/s`；液体止于 100°C，干烧止于 160°C |
| 现象反馈 | 火焰 SVG 带 `prefers-reduced-motion` 分支；≥60°C 的容器描边转暖色；受热容器把说明文字移到右侧避让火焰 |
| 日志 | 等宽日志控制台记录放置、移动、加试剂、倒液、点燃、受热、沸腾、降温等操作 |


## 技术栈

| 层 | 实现 |
| --- | --- |
| 视图 | React 18 |
| 状态 | Zustand 4 |
| 拖拽 | `@dnd-kit/core` 6（步骤 2 接入交互） |
| 打包 | esbuild，输出单文件 IIFE，兼容 `file://` |

## 重建运行时

需要 Node.js 与 npm：

```bash
npm install
npm run build:lab
```

源码修改后必须重新生成 `lab/chem-lab.js`，否则页面仍加载旧运行时。
