# ChemLearn · AP 化学学习与练习平台

> 一个纯前端、可离线运行的 AP Chemistry 学习工具：**细致讲解 + 即时练习 + 错题重练 + 3D 分子可视化 + 辅助工具 + 虚拟实验室**。

ChemLearn 面向“课堂听不懂、课后没人讲、刷题没反馈”的 AP 化学学习者。它把 5 个核心章节拆成 20 个知识点，每个知识点都配有定义（中英对照）、4 段细致讲解、带步骤的举例、易错点与小结；每章配 9 道练习，提交后立即判分并展示详细解析；做错的题自动进入错题集，可重做、可标记已掌握、可一键巩固；常驻的 3D 分子模块内置 33 个分子模型与 46 条中文名称映射，支持旋转、缩放与原子悬停提示；虚拟实验室提供器材/试剂库、点阵实验台与等宽日志控制台，器材可以拖着摆、瓶塞能开合、容器倾斜着倒液（带流动水柱）、试管能夹到铁架台上用酒精灯加热，加入试剂后会按 33 条规则生成沉淀、气泡、置换、放热与受热分解现象。

- **无需后端**：所有数据都是本地文件，所有状态保存在浏览器 `localStorage`。
- **无需安装**：双击 `index.html` 即可运行，也可以用任意静态服务器托管。
- **运行时无外部请求**：主应用使用原生 Canvas 2D；实验室的 React / Zustand / dnd-kit 已预打包进 `lab/chem-lab.js`，不依赖 CDN。

## 一、快速开始

### 方式 1：直接双击（推荐给普通使用者）

直接双击项目根目录的 `index.html`。

为了让 `file://` 协议下也能加载数据，项目同时提供了：

- `data/*.json`：标准 JSON 数据（可读、可校验）
- `data/*.js`：由 `tools/build_data.py` 从 JSON 生成的包装文件，把同一份数据挂到 `window.CHEM_DATA`

`index.html` 通过 `<script>` 加载包装文件，`js/data.js` 优先读取 `window.CHEM_DATA`，读不到时才回退到 `fetch('data/*.json')`。因此**双击打开与本地服务器访问都能正常工作**。

### 方式 2：本地静态服务器

```bash
cd ChemLearn
python3 -m http.server 8000
# 然后浏览 http://localhost:8000
```

### 浏览器要求

- Chrome / Edge / Safari 最新版（项目使用了 `color-mix()`、CSS 变量、`text-wrap: balance` 等现代特性）
- 桌面端与移动端均可使用（已做响应式适配）
- 若浏览器禁用了 `localStorage`，应用会自动退化为“内存模式”，功能可用但刷新后进度丢失

## 五、关键实现说明

### 5.1 单页路由

`js/router.js` 使用 `location.hash` 做前端路由，支持 `:param` 形式的动态段：

```js
CL.router.register('/knowledge/:id', function (params) {
  CL.knowledge.renderPoint(params);
});
```

路由变化时自动更新导航高亮、页面标题、滚动位置；未匹配路径渲染 404 页面。

### 5.2 学习数据持久化

`js/storage.js` 统一使用前缀 `chemlearn.v1.`，包含四个 key：

| key | 内容 |
| --- | --- |
| `chemlearn.v1.progress` | 已读知识点、各章答题次数与正确数、最近访问时间 |
| `chemlearn.v1.wrongbook` | 错题列表（错误次数、首次/最近错误时间、已掌握状态、历史作答） |
| `chemlearn.v1.attempts` | 最近 400 条答题记录（用于统计正确率） |
| `chemlearn.v1.settings` | 3D 模块的自动旋转、标签显示等偏好 |

所有读取都做了 `try/catch`，并在 `localStorage` 不可用时退化为内存存储。

### 5.3 判分与错题流转

1. 用户提交答案 → `CL.quiz.grade(question, answer)` 判分
2. `CL.store.recordAttempt(...)` 写入答题历史，更新章节正确率
3. 答错 → `CL.store.addWrong(question, answer)` 自动入库
4. 答对且该题在错题集中 → 自动标记“已掌握”
5. 错题集中重做答对 → 同样自动标记“已掌握”，并保留历史记录

### 5.4 方程式配平算法

`js/tools.js` 中的 `balance()`：

1. 解析输入，支持 `->`、`→`、`=`、`⇌` 四种箭头，自动去除状态符号与前置系数
2. 用 `CL.molecule.parseFormula()` 解析每种物质的元素计数（支持括号）
3. 反应物取正、生成物取负，构造元素 × 物质的齐次线性方程组 `A·x = 0`
4. 用**有理数**高斯-约当消元求零空间向量（避免浮点误差）
5. 将比例化为最简正整数系数，并校验所有元素守恒
6. 在内置题库中查找相同方程式，若有则展示其分步推导，否则自动生成“设系数 → 列守恒方程 → 求解”的步骤

### 5.5 3D 分子渲染

`js/molecule3d.js` 用原生 Canvas 2D 实现了一个轻量 3D 管线：

- **旋转**：绕 Y 轴、X 轴依次旋转原子坐标
- **透视投影**：`perspective = 9 / (9 + z)`，相机距离 9 Å
- **深度排序**：化学键按平均深度、原子按深度由远到近绘制，实现前后遮挡
- **化学键**：单键 / 双键 / 三键（屏幕空间法线偏移）、芳香键（实线 + 虚线）、离子键（灰色虚线）
- **原子**：CPK 配色 + 径向渐变 + 阴影，白色氢原子自动使用深色标签
- **交互**：Pointer Events 拖拽旋转、滚轮缩放、双击复位、自动旋转、悬停提示、导出 PNG
- **未知物质**：解析中心原子与配体数 → 估算孤对电子 → 得到电子域数与几何构型，并生成示意结构；界面会明确标注“VSEPR 推测”，不会伪装成精确数据

### 5.6 虚拟实验室运行时

实验室采用 React 18 + Zustand 4 + `@dnd-kit/core` 6，源码位于 `lab/src/`：

- `library.js`：7 个分类、34 项器材与试剂，化学式使用 Unicode 下标；第一类「预置试剂瓶」的条目带 `stock: true` / `label` / `reagent`，拖出来就是装着 500mL 液体、贴着标签、塞着瓶塞的整瓶试剂（`createItem()` 按 `shape` 选器型并把 `reagent` 灌进 `contents`）；`reagent-bottle`（细口瓶）带 `stopper: true`，与预置试剂瓶同为带塞容器。
- `reactions.js`：反应规则引擎。`SPECIES` 登记 41 种物质的名称、颜色、pH、是否固体；`RULES` 是 33 条“反应物对 → 生成物”规则（沉淀、碳酸盐 + 酸放气、金属 + 酸、金属置换、中和放热、沉淀溶于酸、受热分解）。`reactContents()` 反复匹配直到没有新反应或达到 400 轮上限，只按化学式匹配、不做化学计量配平，1 份试剂 = 1 次反应，便于教学演示；带 `minTemperature` 的规则（NaHCO₃ / Cu(OH)₂ 80°C、CaCO₃ 120°C）只在容器够热时才触发。
- `store.js`：Zustand 全局状态。保存实验台对象 `items`（容器 / 工具）与日志 `logs`；每个实体都带 `dimensions`（104×128）与坐标，`boundsOf()` / `mouthPoint()` / `overlaps()` / `pourAlign()` 四件几何工具供页面与自测共用（`LAB_GEOMETRY`、`window.CL.lab` 也暴露同一套数值）。容器的 `contents[]`、`volume`、`ph`、`color`、`temperature`、`turbidity` 全部通过 `syncItem()` 收敛，任何操作都不会绕过它。点火由 `lightItem()` 一处收口：火柴划燃后燃烧 `MATCH_DURATION`（9 秒）并由 `tickHeating()` 倒计时，酒精灯只有台面上存在燃着的火柴时才会被点亮。加热来源由 `heatSource()` 判定：先看有没有一张架在火焰上的石棉网托着容器（`gauzeInFlame()` + `onGauze()`），没有才退回 `inFlame()` 的直接受热；隔着石棉网受热记 `evenHeat`，直接受热到 `UNEVEN_TEMPERATURE`（60°C）写一次「受热不均」警告。石棉网与容器的吸附是 `stackGauze()` / `standOnGauze()` 两个原子操作。开合瓶塞由 `toggleStopper()` 收口（`open` 是 `pour()` / `addReagent()` / `dumpLiquid()` 的前置条件）；倾倒动画只把进度写进 `pourFlow`，由 `startPour()` 起、`tickPour()` 每 60ms 推进、结束时调 `pour()` 一次性结算；铁架台夹持由 `clampOnStand()` / `releaseClamp()` 处理，夹住后 `clampedTo` 让容器进入锁定态（`moveItem()` 直接拒绝并写警告），`moveItem()` 对铁架台做刚体平移（夹着的容器同步位移）。
- `Vessel.jsx`：器材出口与工具线稿——酒精灯（含火焰）、火柴（木梗 + 火柴头 + 划燃后的小火苗）、铁架台（底座 + 立杆 + 铁圈 + 螺丝）、玻璃棒、胶头滴管、石棉网（金属框 + 交叉网格 + 石棉垫，烤热后转暖色并透出光晕）、pH 试纸，`LabGraphic` 按 `kind` 把容器交给 `Glass.jsx`；`suffix` prop 让拖拽幽灵的人造 id（`clipPath` / 渐变）与台上原件互不冲突。
- `Glass.jsx`：玻璃容器的 SVG 分层渲染（步骤 1）。`GLASS` 为每种器材记录内腔 `body` 轮廓、液面上下边界、瓶口（烧杯唇边 / 试管与烧瓶的椭圆开口）、内壁高光、壁厚线、刻度与容量瓶颈部刻蚀环；`GlassDefs` 生成每件器材独立的玻璃渐变与液体纵深渐变；`LiquidLayer` 把液体画成顶边为正弦波的 `<path>`，用 `body` 做 `clip-path`，`fill` 有 480ms 过渡（供变色反应用），CSS `lab-liquid-drift` 让整条波形缓慢漂移，固含量 > 0 时再叠一层冷灰白浑浊（`lab-liquid__haze`，不透明度 = `turbidity`）；`SolidMarks` 画底部沉积堆体 + 5 颗浮动颗粒（`lab-solid-mote`），`Bubbles` 画上升气泡（数量随 `gasTimes` 增加），`Steam` 在沸腾时从瓶口升起 5 团模糊水蒸气（`lab-steam-rise`，`prefers-reduced-motion` 下静止）。
- `LabPage.jsx`：左侧分类折叠库、中间点阵实验台、底部仿终端日志；`DndContext` 负责库→画布、画布内自由移动与“试剂→容器”三类拖拽，点击选中后出现操作条。台上器材拖起时由 `DragOverlay` 复制完整 SVG 跟手移动，原位置淡成占位，松手按实测宽高把落点钳制在画布内并置顶；容器互拖用几何判定 `pourAlign()`（把拖拽中的令牌矩形对回画布坐标，比较瓶口 X 中心差 ≤ 26px 与「悬停 / 叠放」两种高度条件），`useDndMonitor()` 在拖拽途中给命中的容器加 `.lab-vessel--pour-ready` 虚线瓶口罩；把火柴拖到酒精灯上会直接点火，其它器材压到灯上仍只当摆放；石棉网与容器互为落点——容器拖到网上吸上去（`standOnGauze()`），石棉网拖到容器上垫到下面（`stackGauze()`）；铁架台也是落点，容器松手时玻璃底中心距铁圈圈心 < 30px 就夹住（`clampOnStand()`），夹住后拖动被 `useDraggable` 禁用。倒液先起 `pourFlow` 动画（`startPour()` + 60ms 的 `tickPour()`），倾斜、水柱与目标液面都跟着进度走，1.1s 后才结算一次；容器上的瓶塞可点，调用 `toggleStopper()` 开合。
- `main.jsx`：把 React 根节点挂到 `#lab-root`，并通过 `CL.router.onLeave()` 在离开 `#/lab` 时卸载，避免残留监听器。

交互与状态规则：

- **操作条**：容器显示 `Status: Open / Closed`、`Vol: 30mL | Temp: 100°C | PH: 5.0`、`Contents: [NaNO₃ 20mL + AgCl 10g + HCl 10mL]` 与受热 / 夹持状态，可“加入试剂 / 倒出 / 清空 / 移除”，夹在铁架台上时多一个「取下」；火柴显示“划燃 / 熄灭”与剩余燃烧秒数，酒精灯显示“点燃 / 熄灭”，未点燃时按台面上有没有燃着的火柴提示「先用火柴划燃」或「用燃着的火柴点燃」。Esc 或点击空白取消选中。
- **倒液**：容器拖到容器上按目标容量与剩余量部分转移，保留温度与 pH；未选中容器时拖入试剂会提示“请把试剂拖到容器中”。是否算“对准”由 `pourAlign()` 用瓶口几何判定（X 中心差 ≤ 26px，且源口高于目标口 6–90px 或两容器中心高差 ≤ 46px），拖拽途中目标容器会套上虚线瓶口罩；倒液带 1.1s 动画：源容器倾斜 38°（`.lab-vessel--pouring`，在目标左侧时镜像成 -38°）、水柱是一条颜色与源液体一致、线宽随转移量变化的流动虚线（`PourStream`，起点 / 落点取自 `mouthPoint()`）、目标液面按进度上涨，动画期间只改“显示体积”，结束后 `pour()` 才写入 `contents` 与日志（每次倾倒只出现一条「将 10mL 液体从 试剂瓶 倒入 烧杯。」）。
- **瓶塞**：试剂瓶是带塞容器，初始 `open: false`，瓶塞按 `translate(-13px,-20px) rotate(15deg)` 抬离瓶口；塞着时倒液、加试剂、倒出都会被挡下并写警告「试剂瓶 的瓶塞没打开，倒不出液体。」，点画布上的瓶塞或操作条上的 `Status: Closed` 读数都可以开合（`toggleStopper()`），日志记「打开 试剂瓶 的瓶塞。」/「塞上 试剂瓶 的瓶塞。」。
- **铁架台**：容器松手时玻璃底中心距铁圈圈心（令牌偏移 67 / 43.5）小于 30px，或直接落在铁架台上，就夹进铁圈（x 对准圈心、玻璃底落在圈心），日志「试管 夹在 铁架台 的铁夹上。」；夹住后容器是锁定实体——拖动被禁用、`moveItem()` 记「试管 已夹在铁架台上，先「取下」再移动。」并拒绝、指针变 `not-allowed`、副标题写「铁夹上」。移动铁架台时夹着的容器同步平移（相对位置不变）；操作条上的「取下」（或移除铁架台）才解锁。夹持容器的火焰判定放宽到 96px，把酒精灯放到试管正下方即可受热。
- **点火**：火柴是唯一的火源，划燃后燃烧 9 秒（`MATCH_DURATION`），副标题「燃烧中 · 9s」每秒递减，燃尽自动熄灭并记「火柴 燃尽了。」；酒精灯必须用燃着的火柴点——选中灯点「点燃」，或直接把火柴拖到灯上（`lightItem()` 一条通路，灯帽随 `lit` 平移让位）。没有火柴时点「点燃」只会写下警告「酒精灯 要用火柴点燃：先取出火柴并划燃。」
- **加热**：点燃酒精灯后按火焰碰撞判定受热——容器中心与火焰中心横向偏差 < 30px，且焰尖到容器玻璃底在 −24 ~ +50px 之间（悬在焰尖上方或焰尖略微探入底部），才每秒升温 `HEAT_RATE`（4°C）；并排摆在灯旁不算受热。移开后每秒降温 `COOL_RATE`（2°C）直到 25°C；有液体时止于 100°C 并转入沸腾（`boiling`：9 颗更密的气泡 + 液面 `lab-liquid-churn` 翻滚 + 瓶口 5 团水蒸气、副标题「沸腾」、警告日志），空容器干烧止于 160°C。
- **匀热**：加热来源由 `heatSource()` 决定，先查石棉网再查直火。石棉网架在火焰上（网心对准焰心 ±34px、网底落在焰尖 −12 ~ +14px）且容器坐在网面上（容器中心对准网心 ±34px、玻璃底落在网面 −8 ~ +16px）时，容器算「隔着石棉网受热」，`evenHeat` 为真，操作条显示「受热: 垫石棉网 · 均匀受热」；没有网就直接架在火焰上的容器，升温到 60°C 时写一条「烧杯 直接架在火焰上，玻璃受热不均（建议垫上石棉网）。」——`unevenWarned` 保证每件容器只记一次，温度回落到室温后复位。把石棉网拖到容器上时 `stackGauze()` 一次 `set()` 完成「网面落到焰尖上方 + 容器抬到网面上」，日志只写「石棉网 垫在 烧杯 与火焰之间。」。加热速率不因垫网打折——教学重点是「受热均匀」，不是「加热更慢」。
- **反馈**：火焰为三层 SVG 并带 `prefers-reduced-motion` 分支，火焰上有容器或石棉网时外焰增亮、光晕放大 1.28 倍；温度 ≥60°C 的容器描边转暖色；受热容器的说明文字自动移到右侧避让火焰（窄屏上限收到 148px，保证「100°C · 沸腾 · 10 / 250 mL」不被省略号截断），石棉网的名称与副标题也右移到 `calc(50% + 40px)`，不压在网面上；容器层级永远高于工具，火焰只从底部缝隙透出；被火焰烤着的石棉网加 `lab-vessel--gauze-hot`，网格与石棉垫转暖色、网下透出 `lab-gauze__glow` 光晕、副标题写「匀热中」；划燃的火柴头复用同一套三层火苗，副标题转暖色，和酒精灯的「燃烧中」呼应。
- **渲染**：容器全部由 SVG 分层绘制——玻璃本体用 `currentColor` 渐变（左侧反光、右侧略深的玻璃厚度）+ 半透明填充，内壁白色高光、壁厚线、刻度与瓶口线画在液体之上；液体顶边是 12 段正弦波的 `<path>`，被内腔 `clip-path` 裁切，CSS 以 9s 周期做 ±8px 横向漂移，形成轻微液面起伏；液面高度按「体积 ÷ 容量」的 0.75 次幂映射（10mL / 250mL 也看得见，相对高低仍随体积单调），液体填充色带 480ms 过渡；`prefers-reduced-motion` 下波浪与气泡动画一起停止。
- **反应**：每次加试剂 / 倒液 / 清空后由 `settleContents()` 调用 `reactContents()` 结算，结果经 `applySettled()` 一次性写回并补日志，日志正文统一以「发生反应：」开头。沉淀按质量画成容器底部的弧形固体（颜色取自 `SPECIES`）并撒 5 颗浮动颗粒，生成时带 `lab-solid-settle` 下沉动画，同时由固含量算出 `turbidity` 让液体变浑（`lab-liquid__haze`，640ms 过渡）；放气时液面下升起的气泡数随 `gasTimes`（同一次操作里规则触发次数）从 4 颗增加到 10 颗，容器右上角显示 `↑ CO₂` 徽标，`GAS_DURATION`（6s）后气泡、徽标与现象文字一起收起；中和反应放热最多 +65°C，放气按 `loss` 扣减液体体积。操作条里的“现象: …”一行来自规则自带的 `phenomenon` 文案。
- **受热分解**：规则可带 `minTemperature`（NaHCO₃ / Cu(OH)₂ 80°C、CaCO₃ 120°C），`tickHeating()` 在每次温度变化后把当前温度传回 `reactContents()`，够热就立即分解并写入日志（如“蓝色沉淀变成黑色固体（CuO）”），到 100°C / 160°C 上限后仍继续分解剩余固体；纯固体分解按 1g ≈ 1mL 折算产物液体，标了 `state: 'solid'` 的产物（如 Na₂CO₃）不占液体体积。
- **指示剂**：酚酞 / 石蕊加入后，`indicatorTint()` 按混合液 pH 覆盖液体颜色（酚酞 pH > 8.2 变红、石蕊酸红碱蓝），`indicatorText()` 在 pH 翻转时补一条“酚酞遇碱变红（pH 13.0）”式日志。

为了继续支持 `file://` 双击运行，React、Zustand 与 dnd-kit 由 esbuild 预打包为 `lab/chem-lab.js`，以普通 `<script>` 加载；运行时不需要 Node、npm、CDN 或网络。修改 `lab/src` 后执行：

## 九、已知限制与后续扩展

**已知限制**

1. 3D 分子坐标是“理想几何 + 标准键长”的教学级数据，键长键角为近似值，不能用于科研计算。
2. VSEPR 推测只处理主族元素、单中心分子；对有机大分子、配合物、过渡金属化合物可能给出过于简化的结果，界面已明确标注“推测”。
3. 配平助手面向常见无机 / 简单有机方程式，不支持氧化还原半反应配平、离子方程式电荷配平与有机反应机理。
4. 数据全部在本地，清除浏览器数据会丢失学习记录（可在错题集页导出备份）。
5. 未做 Service Worker 离线缓存；不过因为所有资源都是本地文件，直接打开时本来就是离线的。
6. 虚拟实验室已完成步骤 1–5（骨架、器材/试剂库、拖拽与倒液、容器温度/pH/体积、酒精灯火焰碰撞加热、33 条反应规则与指示剂变色、受热分解）与渲染增强 1–5（白底玻璃与三层火焰酒精灯、画布内自由拖动、火焰碰撞加热、火柴点火、石棉网匀热）以及交互增强 6（带塞试剂瓶与开塞门禁、1.1s 倾斜倒液动画与水柱、铁架台铁夹吸附与夹持加热、沸腾液面翻滚）；反应引擎只按化学式匹配、不做化学计量配平，1 份试剂按 1 次反应结算，生成气体的体积按规则给的 `loss` 扣减，固体产物折算成等量液体体积，因此质量与体积是教学级近似，不用于定量计算；受热分解的门槛温度也是教学近似（真实煅烧石灰石需 800°C 以上）；石棉网只改变「受热是否均匀」与提示文案，不改变升温速率，也不模拟真实热传导的延迟；液面高度按「体积 ÷ 容量」的 0.75 次幂映射，只为让少量液体也看得见，不代表真实几何比例。交互增强 6 的倾倒动画固定 1.1s（不随体积变长），水柱是单条曲线示意而非流体仿真；只有试剂瓶带瓶塞（试管 / 烧杯按敞口容器处理，`open` 恒为 `true`）；铁夹按铁圈圈心的固定偏移夹持，不支持任意角度与夹持力。
